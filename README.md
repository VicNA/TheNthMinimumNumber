# Тестовое задание

## Стек проекта

Java 21, Spring, Swagger, Lombok, Maven

# Сборка проекта:

1. Клонируйте  проект

2. Выполните сборку:

```bash
mvn clean package
```
3. Запустите приложение:

```bash
java -jar target/nth-min-service-1.0.0.jar
```

## Альтернативный запуск (без сборки JAR):

```bash
mvn spring-boot:run
```

# Доступ к Swagger:

После запуска приложения откройте в браузере:

```text
http://localhost:8080/swagger-ui.html
```
